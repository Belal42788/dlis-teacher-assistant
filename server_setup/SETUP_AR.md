# تجهيز سيرفر المدرسة (مرة واحدة بس — بيعملها شخص واحد من الإدارة أو بلال)

1. ادخل على supabase.com واعمل حساب مجاني (Sign up).
2. اضغط **New project** → اكتب اسم (مثلاً DLIS) → اختار كلمة سر قوية للقاعدة واحفظها → اختار أقرب منطقة → **Create**. استنى دقيقتين.
3. من القائمة الشمال اختار **SQL Editor** → **New query** → افتح ملف `schema.sql` اللي جنب الملف ده، انسخه كله والصقه → اضغط **Run**. لازم تظهر كلمة Success.
4. من **Project Settings → API** انسخ حاجتين:
   - **Project URL** (شكله https://xxxx.supabase.co)
   - **anon public key** (المفتاح الطويل)
5. من **Authentication → Users → Add user** اعمل حساب لكل واحد (إيميل + كلمة سر) وفعّل **Auto Confirm User**.
6. من **Table editor → profiles** غيّر عمود **role**: المدير والـ HR = `admin`، كل مدرس = `teacher`. أولياء الأمور بيفضلوا `parent`.
7. في برنامج المدرس: **الإعدادات → سيرفر المدرسة** → الصق العنوان والمفتاح → احفظ → اكتب إيميلك وكلمة السر → **تسجيل الدخول** → **جرّب الاتصال**. لازم تظهر كلمة «متصل».

ملحوظة: المفتاح العام (anon) مش سر، الحماية كلها عن طريق صلاحيات الجداول اللي في `schema.sql`. ما تنشرش أبداً مفتاح اسمه service_role.

## لو عملت التجهيز قبل كده وجالك تحديث (مرحلة 12ج)
افتح **SQL Editor** وشغّل ملف `schema.sql` كله تاني. مفيش خوف: بيضيف الجديد بس (صور الإعلانات) ومبيمسحش حاجة.

## بوابة أولياء الأمور (مرحلة 12د)
1. افتح ملف `portal/config.js` واكتب فيه عنوان السيرفر والمفتاح العام (نفس اللي في برنامج المدرس).
2. لو عايز المدرسين ما يكتبوش العنوان والمفتاح: اكتبهم كمان في `resources/school_server.json` قبل ما توزع البرنامج.
3. **النشر على GitHub (مشروعك كله في مستودع واحد، فمفيش داعي تفصل البوابة):** فيه ملف جاهز `.github/workflows/pages.yml` بينشر فولدر `portal` بس.
   - ارفع المشروع على GitHub (فرع `main`).
   - من المستودع: **Settings ← Pages ← Source: GitHub Actions**.
   - اضغط **Actions** وشغّل «Publish parents portal» (Run workflow) أو ابعت أي تعديل في فولدر `portal`.
   - بعد دقيقة هتلاقي الرابط في Settings ← Pages. هو اللي هتديه للأولياء.
   - أي تعديل على `portal/config.js` بيتنشر لوحده.
4. من Supabase: Authentication ← Providers ← Email: **اقفل Confirm email** (الكود هو التأكيد).
5. من Authentication ← URL Configuration: حط رابط البوابة في Site URL، عشان رابط «نسيت كلمة السر» يرجّع لها.
6. من برنامج المدرس (حساب admin): الإعدادات ← سيرفر المدرسة ← «اعمل شيت الأكواد». اطبع الشيت وسلّم كل ولي أمر كود ابنه.
7. شغّل `schema.sql` كله تاني (آمن، بيضيف الجديد ومبيمسحش). التحديث الأخير بيضيف: خطة الأسبوع لكل مادة، كود يخدم ولي أمرين، وصلاحيات أضيق للمدرسين.


## لما تبيع البرنامج لمدرسة جديدة
1. اعمل مشروع Supabase جديد للمدرسة وشغّل `schema.sql` فيه.
2. افتح `resources/school_server.json` واكتب `url` و`key` واسم المدرسة في `school` (مثال: `{"url": "https://xxxx.supabase.co", "key": "…", "school": "اسم المدرسة"}`).
3. ابني البرنامج (`build_windows.bat`) وسلّمه للمدرسة: المدرسين مش هيكتبوا أي حاجة غير إيميلهم وكلمة سرهم.
4. لو مش عايز تبني نسخة لكل مدرسة: استخدم "كود المدرسة" من الإعدادات بعد ما تسجل دخول كإدارة.

## عشان المشروع المجاني ميقفش (مرحلة 17أ)
فيه ملف `.github/workflows/keepalive.yml` بيبعت طلب صغير للسيرفر كل 3 أيام.
1. على GitHub: Settings ← Secrets and variables ← Actions ← New repository secret.
2. اعمل سر اسمه `SUPABASE_URL` وقيمته عنوان السيرفر (https://xxxx.supabase.co).
3. واعمل سر تاني اسمه `SUPABASE_ANON_KEY` وقيمته المفتاح العام (anon / publishable).
4. من Actions شغّل «Keep school server awake» مرة للتجربة. لازم يطلع أخضر.

## نسخة احتياطية
من برنامج المدير: الإعدادات ← سيرفر المدرسة ← «اعمل نسخة احتياطية دلوقتي». اعملها مرة في الشهر. بتتحفظ في فولدر `_backup`.
(الملفات والصور في التخزين مش داخلة فيها.)
