Arabic font for the whole app (optional).

1. Download "Cairo" (free) from  https://fonts.google.com/specimen/Cairo  -> "Get font" -> "Download all".
2. From the zip take the variable font file (named like Cairo[slnt,wght].ttf), rename it to  arabic.ttf  and put it in this folder.
   (If the zip has only static files, use Cairo-Regular.ttf as arabic.ttf and Cairo-Bold.ttf as arabic-bold.ttf.)
3. Start the app again. Nothing else to change. Remove the file to go back to the system font.

Other good Arabic fonts: Tajawal, Almarai, IBM Plex Sans Arabic, Noto Kufi Arabic (all free on Google Fonts, same steps).
