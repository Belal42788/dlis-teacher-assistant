# Restructure plan (Phase 14)

Principle: group by what the teacher is doing, not by type of page. One place per job; one source of truth for "what is taught this week" (the Scheme of work).

## Menu (Timetable and Calendar stay top-level; lesson-reminder settings stay in Settings, the "new reminder" form stays in Tasks)
- My day: Today · Timetable · Calendar · Tasks & reminders
- Prepare: Plan (Scheme of work, makes the trimester-plan Word file) · Create (drop-down: whole week / lesson plan / quiz / revision+cover / slides / grading sheet) · Library (tabs: My files · Shared with students · Sources) · AI chat
- School: Classes (Students · Lesson log · Progress) · Communication (Announcements · Parents' week plan) · Follow-up (admin only) · Map
- Settings (About you · Data & backup · Reminders · AI incl. "how the AI writes" · School server, admin/IT only) · Help

## Moves
- Slides -> a choice in Create. Trimester plan -> button on Plan. "How the AI writes" -> Settings > AI.
- Publish page -> tab "Shared with students" in Library (files and links, approve / hide).
- Create takes topic, source and pages from Plan automatically.

## Phases
- 14a menu and moves (same pages, new places)
- 14b inside each page: order = pick, content, action, result; Today shows "prepare my week" status; Plan feeds everything
- 14c consistency pass, tests, e2e, wording
